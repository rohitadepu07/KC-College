# K.C. College of Engineering and Management Studies and Research

A premium, modern institutional website built with React, Tailwind CSS, and Framer Motion. This project features a high-end aesthetic tailored for a leading engineering institute, focusing on performance, interactivity, and brand-aligned design.

## ✨ Key Features

- **Premium Header Design**: A sophisticated glassmorphism header with a dual-row layout, integrated identity bar, and mobile-responsive navigation.
- **Dynamic Hero Section**: Featuring rotating titles with animated underlines and a high-impact background carousel showing the campus life.
- **Interactive Placements Gallery**: A custom `InfiniteSlider` showcasing industry partners (Infosys, TCS, LTI, etc.) with official logos and smooth transition effects.
- **Advanced UI Animations**:
  - **Sparkles Background**: A dynamic particle system powered by `tsparticles` for a prestigious atmosphere.
  - **Progressive Blur**: Sophisticated edge-fading for scrolling components.
  - **Framer Motion**: Smooth entry animations and micro-interactions across the landing page.
- **Bespoke Typography**:
  - **Heading**: [Lilita One](https://fonts.google.com/specimen/Lilita+One) for a bold, friendly, and modern institutional feel.
  - **Accent**: [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) for italicized, high-end emphasized text.
  - **Body**: System sans-serif for optimal readability.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (Latest LTS recommended)

### Installation

1.  **Clone the repository:**
    ```bash
    git clone [repository-url]
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    ```

4.  **Build for production:**
    ```bash
    npm run build
    ```

## 🛠️ Technology Stack

- **Framework**: React 18
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion, @tsparticles
- **Components**: Radix UI (accessible primitives)
- **Icons**: Lucide React
- **Measurement**: react-use-measure
